LARM HUB — FRONTEND 0.3.82 (INCREMENTAL)
=========================================

Este pacote contém somente os arquivos alterados da versão 0.3.81 para a 0.3.82.
Não é cumulativo.

CORREÇÃO
--------
A inativação do Movimento Orçado passa a utilizar POST em vez de PATCH.
O backend 0.3.82 aceita POST e PATCH para manter compatibilidade.

PUBLICAÇÃO
----------
1. Publique primeiro o backend 0.3.82 e reinicie a API com PM2.
2. Depois copie/publique este frontend no Vercel.
3. Atualize o navegador com Ctrl + F5.
